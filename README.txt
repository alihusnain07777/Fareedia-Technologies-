FAREEDIA TECHNOLOGIES - website + installable app

Is folder ki saari files EK SAATH upload karni hain (sirf index.html nahi):
  index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png,
  icon-maskable-512.png, apple-touch-icon.png

GitHub Pages par:
1. GitHub par naya repository banao (Public).
2. "Add file > Upload files" se ye saari files upload karo (zip nahi, files khol kar).
3. Settings > Pages > Branch: main, folder: / (root) > Save.
4. 1-2 minute baad aapka https link ban jata hai. Usay Chrome mein kholo.

Install karna:
- Android Chrome: menu (3 dots) > Install app / Add to Home screen. Ya page ke upar "Install app" button.
- Desktop Chrome/Edge: address bar mein install icon, ya page ka "Install app" button.
- iPhone Safari: Share > Add to Home Screen.
Install ke baad logo aur naam "Fareedia" phone/desktop ki screen par app ki tarah aa jata hai.

Zaroori: install sirf https link (ya localhost) par hota hai. File ko seedha phone mein khol kar install nahi hota.
